# Gospel Logic Map

1. If moral judgment is real, then there is a moral standard.
- Plain-language explanation: if some things are really wrong, there must be a real standard beyond opinion.
- Possible objection: morality is only social preference.
- Short answer: preference does not explain why guilt feels binding.
- Bible passage to support later: Romans 2:14-16; Romans 3:19-20
- Source need if any: moral realism / metaethics

2. If there is a moral standard, then there is law.
- Plain-language explanation: a real standard acts like moral law.
- Possible objection: morality is just personal or tribal preference.
- Short answer: preference does not carry obligation.
- Bible passage to support later: James 2:10-12
- Source need if any: philosophy of ethics

3. If there is law, then there is authority.
- Plain-language explanation: law requires a lawful authority behind it.
- Possible objection: society creates moral rules.
- Short answer: society can describe customs, but it cannot create ultimate moral authority.
- Bible passage to support later: Isaiah 33:22; James 4:12
- Source need if any: theology / philosophy

4. If there is authority, then there is a Judge.
- Plain-language explanation: law without judgment is not really law.
- Possible objection: judgment sounds harsh.
- Short answer: judgment is part of justice.
- Bible passage to support later: Romans 14:10-12
- Source need if any: none needed

5. If we break the law, we are guilty.
- Plain-language explanation: guilt is the result of real wrongdoing.
- Possible objection: people make mistakes, but that is not guilt.
- Short answer: some mistakes are also guilt when they violate what is right.
- Bible passage to support later: Romans 3:23
- Source need if any: none needed

6. If God is righteous, guilt cannot simply be ignored.
- Plain-language explanation: a good judge does not wave away evil.
- Possible objection: why not just forgive?
- Short answer: justice must be answered, not ignored.
- Bible passage to support later: Exodus 34:6-7; Romans 3:25-26
- Source need if any: atonement theology

7. If sin earns death, then the debt is life.
- Plain-language explanation: sin is serious enough that it costs life.
- Possible objection: that sounds severe.
- Short answer: that is why the cross matters.
- Bible passage to support later: Romans 6:23
- Source need if any: Bible support

8. If we cannot pay and live, we need a substitute.
- Plain-language explanation: if the debt is life, our own effort cannot erase it.
- Possible objection: can good works cancel bad works?
- Short answer: no; good works do not remove guilt.
- Bible passage to support later: Ephesians 2:8-9; Titus 3:5
- Source need if any: atonement theology

9. If Jesus is sinless, He can stand in the place of sinners.
- Plain-language explanation: only someone without guilt of His own can represent others.
- Possible objection: why Jesus?
- Short answer: because He is uniquely righteous and sufficient.
- Bible passage to support later: 2 Corinthians 5:21; Hebrews 4:15
- Source need if any: Christology / atonement

10. If Jesus rose from the dead, death did not defeat Him.
- Plain-language explanation: resurrection means Jesus is alive and vindicated.
- Possible objection: resurrection is impossible.
- Short answer: that objection assumes naturalism before the evidence is weighed.
- Bible passage to support later: 1 Corinthians 15:3-8
- Source need if any: historical Jesus / resurrection sources

11. If Jesus paid the debt, forgiveness can be just.
- Plain-language explanation: the cross means justice is not ignored.
- Possible objection: why blood?
- Short answer: blood means life given; it shows the cost of sin.
- Bible passage to support later: Leviticus 17:11; Hebrews 9:22
- Source need if any: atonement theology

12. Therefore the gospel is not God ignoring justice; it is God satisfying justice through Christ.
- Plain-language explanation: God is both just and loving in the same act.
- Possible objection: this sounds like legal fiction.
- Short answer: it is not fiction if Jesus really died and rose again.
- Bible passage to support later: Romans 3:25-26
- Source need if any: historical resurrection support
