# Start Here — Mind

Mind is Steve's human-first personal and organizational knowledge system.

## Operating model

```text
Mind provides orientation and human authority.
Brain provides AI capability and execution.
```

Do not load the whole vault. Read this file, current context when needed, the memory map, and then only relevant pages.

## Human entrypoint

Steve normally starts from `home.md` and the current task surface defined by `system/task-kanban-contract.md`.

## Target structure

```text
inbox/         capture, raw source, processed proposals, and failures
organizations/ businesses, ministries, and long-lived entities
projects/      active outcomes and deliverables
repos/         human-readable context for code repos and apps
people/        people and relationships
faith/         Bible, theology, apologetics, ministry, and faith resources
knowledge/     durable non-faith understanding and decisions
resources/     source material and research
history/       completed, superseded, inactive, and historical material
system/        Mind policy, agent context, contracts, reports, and templates
```

Legacy folders are compatibility or historical surfaces. Use `system/folder-contract.md` before changing them.

## Retrieval order

1. `00-current-context.md` for current priorities.
2. `00-memory-map.md` for routing.
3. canonical domain pages.
4. `resources/` for evidence.
5. `history/` only when historical context is relevant.

## Authority rule

Recent explicit human decisions and current canonical pages outrank captures, generated summaries, inferred graph edges, and old history. When evidence conflicts, show the conflict.

## Safety

Mind must remain useful without Brain, a model, Graphify, embeddings, or continuous automation. Important truth and commitment changes remain human-approved.
