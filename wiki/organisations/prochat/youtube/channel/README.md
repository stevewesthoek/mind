## Current operating model

### ProChat Memory for QA

Videos may demonstrate:

- repeated QA investigation problems;
- test-failure evidence;
- reviewed lessons;
- current evidence overriding stored memory;
- local Markdown and Git workflows;
- sanitization and project boundaries;
- selected beta onboarding;
- tester feedback and case-study learning.

### ProChat Workbench

Videos may demonstrate:

- connecting ChatGPT to a local source;
- exact repository or knowledge-folder context;
- bounded reads and writes;
- guarded execution;
- targeted validation;
- explicit Git staging and commits;
- protecting unrelated worktree changes;
- installation, onboarding, and responsible comparisons.

## Publishing rule

A video is approved only when:

- one product lane is selected;
- the demonstration uses current product behavior;
- claims are supported by visible evidence or approved documentation;
- private information is removed;
- limitations are stated honestly;
- the call to action matches the selected lane;
- Steve reviews and publishes it manually.
