# Wiki Log

Append-only knowledge-maintenance ledger for the Mind OS wiki.

This file records human-readable maintenance events such as ingests, compilations, lint passes, important queries, accepted updates, and rollback notes.

It is not a Brain runtime log, approval audit, scheduler report, or JSONL store. Brain-owned runtime state stays in the Brain repo and is surfaced through Brain Core summaries.

## Format

- YYYY-MM-DD — event type — short human-readable summary — source/capture links when useful
