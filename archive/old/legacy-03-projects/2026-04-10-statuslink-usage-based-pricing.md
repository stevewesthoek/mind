# StatusLink Usage-Based Pricing Model

## Summary

Transition StatusLink from seat-based licensing to usage-based pricing (API call metering) to improve margins by ~40% and align pricing with actual customer value delivery.

## Opportunity

- **Current model:** Seat licenses (fixed cost per user)
- **Proposed model:** Pay-per-API-call metering (variable cost aligned with usage)
- **Expected benefit:** 40% margin improvement through better alignment with customer consumption patterns

## Key Points

- Research Stripe's metering API capabilities and integration requirements
- Design new pricing calculator UI for customer self-service estimation
- Plan migration strategy for existing seat-licensed customers (grandfather period, conversion incentives)
- Analyze competitor approaches (Twilio, SendGrid, etc.)
- Model financial impact on different customer segments

## Action Items

- [ ] Research Stripe metering API documentation and case studies
- [ ] Define pricing tiers and per-call rates
- [ ] Design UI wireframes for pricing calculator
