# Organizations

Long-lived entities live here: businesses, ministries, non-profits, communities, and other institutions Steve owns, leads, serves, or tracks.

Examples include ProChat, Arkware, Yeshua Academy, church/ministry contexts, and client organizations when they become durable context.

An organization page should link to related projects, repos, people, decisions, strategy, resources, and history.

Compatibility note: legacy organization knowledge may still live under `wiki/organisations/` until migration.
