# ProChat Future Capabilities

**Status:** canonical future-capability boundary  
**Owner:** Steve Westhoek  
**Last updated:** 2026-07-01

## Purpose

This document records capabilities that may be developed later without presenting them as current products.

ProChat currently has exactly two products:

```text
ProChat Memory
ProChat Workbench
```

Automation capabilities, API access, and MCP integrations are not current products.

A future capability must remain inside an existing product unless the canonical naming architecture is deliberately changed.

## Automation capabilities

ProChat Memory may later help users turn reviewed memory and current input into repeatable outputs or actions.

Possible examples include:

- recurring summaries;
- review checklists;
- investigation preparation;
- report drafts;
- approved low-risk actions.

Automation must remain review-first and evidence-aware. It is not a current standalone product.

## API access

A future API may provide programmatic access to approved ProChat capabilities.

Possible uses include:

- local memory retrieval;
- approved memory updates;
- workspace validation;
- guarded project operations;
- integration with customer-owned tools.

There is no current public API product or commercial API offer.

## MCP integrations

MCP integrations may allow compatible AI clients to use approved local ProChat capabilities.

For ProChat Memory, this may expose local retrieval, draft, review, approval, and validation operations.

For ProChat Workbench, MCP-compatible access may support exact context and guarded local actions where the technical architecture permits it.

MCP is an integration method, not a product.

## Promotion rule

A future capability may be promoted into the current strategy only when:

1. it exists and is usable;
2. its product ownership is clear;
3. its safety and data boundaries are documented;
4. its licensing implications are understood;
5. the canonical naming architecture is updated where necessary.

Until then, future capabilities must not appear as product cards, current offers, or active revenue lines.
