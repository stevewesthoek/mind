# Graphify Output

Generated graph artifacts for the Mind knowledge base live here.

## Files

- `graph.json` — generated machine-readable graph data.
- `GRAPH_REPORT.md` — generated graph report for human review.
- `manifest.json` — generation manifest and run metadata.
- `cache/` — generated cache used by the graph process.

## Current status

This folder currently stores graph data and reports. A clickable visual graph artifact such as `graph.html` is not confirmed here yet.

## Rules

- Treat this folder as generated output unless a file explicitly says otherwise.
- Do not manually edit generated graph artifacts as the source of truth.
- Source knowledge should remain in the Mind notes; this folder should be refreshed from those notes.
- Future visual graph output should be documented here and linked from the root graph overview.
